# 管理后台操作手册

> 适用版本：v2.7.0 起的任务型管理后台。旧入口 `/admin/dashboard?tab=...` 仍可访问，会自动跳转到下表对应的新路由。

## 1. 路由总览

| 任务页 | 路由 | 旧入口（兼容跳转） |
| --- | --- | --- |
| 概览 | `/admin/overview` | `?tab=stats` |
| 项目 | `/admin/projects` | `?tab=projects` |
| 生成激活码 | `/admin/licenses/generate` | `?tab=generate` |
| 激活码管理 | `/admin/licenses` | `?tab=list` |
| 消费日志 | `/admin/consumptions` | `?tab=consumptions` |
| 审计中心 | `/admin/audit` | `?tab=auditLogs` |
| API 接入 | `/admin/integration` | `?tab=apiDocs` |
| 商品管理 | `/admin/shop/products` | `?tab=shop` |
| 订单管理 | `/admin/shop/orders` | `?tab=shop` |
| 支付渠道 | `/admin/shop/payment` | `?tab=shop` |
| 系统设置 | `/admin/settings` | `?tab=systemConfig` |
| 账户安全 | `/admin/settings/security` | `?tab=changePassword` / 用户菜单 |

通用约定：

- **筛选/分页可分享**：项目、激活码、消费、审计页的关键词、状态、排序、页码均写入 URL query，刷新与分享不丢上下文。
- **危险操作二次确认**：删除、停用、清理类操作统一弹出确认框，显示目标对象与影响范围；提交中按钮锁定。
- **详情用抽屉**：行点击或「更多 → 详情」在右侧抽屉打开，Escape / 遮罩关闭后焦点回到触发元素。
- **移动端**：侧栏收进抽屉导航；表格横向滚动；触控目标 ≥40px。

## 2. 概览 `/admin/overview`

1. 顶部 4 个 KPI（总激活码 / 已使用 / 可用 / 已过期）。
2. 使用率统计 + License API 指标（5 分钟窗口）。
3. 最近操作列出最新 5 条审计，点「查看全部」进入审计中心。

## 3. 项目 `/admin/projects`

- **新建项目**：右上主动作 → 弹框填写名称、projectKey、描述与默认换绑策略。projectKey 仅限小写字母、数字与连字符。
- **搜索 / 状态 / 排序**：工具栏一行完成，写入 URL。
- **编辑基础信息**：行尾「更多 → 编辑基础信息」（默认项目名称固定，仅描述可改）。
- **换绑策略**：「更多 → 项目详情」抽屉内的「换绑策略」分区，改后点「保存策略」。
- **停用 / 启用 / 删除**：「更多」菜单；默认项目不可停用（行内与抽屉均有提示）。
- 复制 projectKey：点击表格中的 key 或抽屉内「复制标识」。

## 4. 生成激活码 `/admin/licenses/generate`

三段式表单：

1. 基础信息：所属项目（停用项目不可选）、授权类型（时间型/次数型）、数量。
2. 授权条件：时间型填套餐类型与有效期（选「自定义」才可改天数）；次数型填总次数。
3. 高级换绑策略：默认折叠，留空继承项目级设置。

提交后结果区列出本次生成的激活码，可逐条复制或整批导出 CSV。

## 5. 激活码管理 `/admin/licenses`

- **筛选**：关键词（激活码 / machineId）、状态、项目、套餐类型 + 导出筛选结果 + 清理过期绑定（确认框）。
- **行操作**：点击激活码打开详情抽屉；「更多」含详情、复制、删除。
- **详情抽屉**：概要、单码换绑策略（含操作原因，记入审计）、设备强制解绑/换绑、绑定历史与管理员操作时间线。

## 6. 消费日志 `/admin/consumptions`

- 搜索 requestId / machineId / 激活码 + 项目筛选；「时间范围」折叠面板支持起止时间与快捷区间。
- 「自动刷新」开关默认开启：筛选变化后 400ms 自动拉取；关闭后仅手动刷新。
- 行点击或「详情」打开抽屉，可复制 requestId / machineId 用于排障。
- 空结果时导出按钮禁用。

## 7. 审计中心 `/admin/audit`

- 筛选：管理员 / 目标 / 原因关键词、项目、操作类型、时间范围；导出 CSV。
- 表格不展示原始 detail JSON；行点击「详情」在抽屉中查看操作概要与时间线。

## 8. 购买中心

三个子页共享子导航，各自独立加载数据：

- **商品 `/admin/shop/products`**：列表优先；「新建商品」弹框（绑定项目、授权类型、价格、库存模式）；「更多」内编辑、预定义码补货（1-100）、上下架、删除（确认框）。
- **订单 `/admin/shop/orders`**：状态/渠道筛选；待支付订单行内「确认收款发卡」；「清理超时订单」独立确认框；点击订单号打开详情抽屉（摘要、联系方式、投递信息、重发邮件）。
- **支付渠道 `/admin/shop/payment`**：每个渠道一张卡，展示启用状态、配置完整性、缺失字段；配置区默认折叠；webhook secret 输入框默认掩码，可显示/隐藏；保存后立即生效。

## 9. 系统设置 `/admin/settings`

- 概览：配置项 / 白名单 / 登录会话 / 密码强度摘要 + 分区链接卡。
- 分区（访问白名单、换绑策略、认证与会话、系统展示、通知告警、高级配置）通过 `?section=` 寻址；分区内为单一表单区。
- 有未保存修改时底部出现保存栏：显示未保存数量，支持重置（重新拉取）与保存（等同表单内「保存配置」）。
- 部分敏感配置（密钥类）默认掩码，需点击可见后再编辑。

## 10. 账户安全 `/admin/settings/security`

- 入口：设置页「账户安全」卡片、用户菜单「修改密码」。
- 填写当前密码 + 新密码 + 确认密码；右侧实时校验清单。
- 修改成功后页面显示 3 秒倒计时并自动退出登录（所有旧会话失效）。

## 11. API 接入 `/admin/integration`

- 左侧章节目录（移动端折叠下拉）：接入概览 / 正式接口 / 多语言示例 / 后台联调；选择写入 `?section=`。
- 「后台联调」在页头有直达按钮。
- 接口与示例代码块可折叠，右上「复制」按钮反馈复制结果。

## 12. 键盘与可访问性

- 所有弹框/抽屉：Escape 关闭、遮罩点击关闭、关闭后焦点恢复。
- 页面唯一 `h1`；图标按钮均有 aria-label；按钮触控尺寸 ≥40px。
- 支持中/英/日/韩/西/法/德/葡/俄/阿拉伯语；阿拉伯语自动 `dir=rtl`。

## 13. 常见问题

| 现象 | 处理 |
| --- | --- |
| 旧书签 `/admin/dashboard?tab=xxx` 打开 | 自动 302 到对应新路由，无需改收藏 |
| 列表数据为空 | 先检查 URL 筛选参数；「重试」按钮保留原筛选重新拉取 |
| 支付渠道显示「配置不完整」 | 进入对应渠道折叠区补齐缺失字段（卡下方列出缺失 key） |
| 改密后提示重新登录 | 属预期行为，3 秒后自动跳转登录页 |
